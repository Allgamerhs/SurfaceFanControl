SURFACE FAN CONTROL - INSTALLABLE MONITORING EDITION

This package provides a standard Windows setup wizard, a selectable installation folder,
a Start Menu shortcut, an optional desktop shortcut, and a start-with-Windows option.

The default installation folder is C:\Program Files\SurfaceFanControl. The folder can be
changed in the wizard, and installing under Program Files requires administrator approval.

This public edition runs in monitoring mode only. It contains no kernel driver,
privileged service, or WinRing0 component and performs no hardware fan-control writes.
